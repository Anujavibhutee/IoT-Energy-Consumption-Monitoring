# IoT-Based Energy Consumption Monitoring System

## Project Overview
This project is an IoT-based energy monitoring dashboard developed using Python and Streamlit. It provides a visual interface for monitoring and analysing energy consumption data.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Features
- Interactive energy monitoring dashboard
- Data visualisation
- Graphical representation of energy data
- User-friendly dashboard interface

## Project Structure
- main.py - Main application code
- requirements.txt - Required Python libraries
- screenshots/ - Dashboard screenshots
- README.md - Project documentation

## Installation and Setup

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

pip install -r requirements.txt

4. Run the application:

streamlit run main.py
